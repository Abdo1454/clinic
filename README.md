# Scan App

A simple and interactive web application built using HTML, CSS, and JavaScript that simulates a scanning interface experience.

## 🚀 Overview

This project demonstrates how to build a clean and responsive UI using vanilla web technologies. It focuses on user interaction, layout design, and basic JavaScript logic without using any frameworks.

## ✨ Features

* Responsive design for different screen sizes
* Clean and modern UI layout
* Interactive scanning simulation
* Image/UI preview handling
* Lightweight and fast performance

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
